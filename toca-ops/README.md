# Suitee Ops Service

Service responsible for Operations management in the Suitee ecosystem.

## Responsibilities
- **Maintenance**: Manage repair tickets for properties.
- **Keys**: Manage property keys and access logs.
- **Inspections**: Manage property inspections.

## Stack
- Go 1.25+
- Gin Web Framework
- Postgres (Supabase)
- Docker

## Running
```bash
make run
```
